## Context

A local web tool acting as a **personal table tennis coach**: plan design, data entry/storage,
analysis, comparison, training direction & motivation. The tool has **multiple tabs**, built one at
a time. **Tab 1** is an Excel-like grid for logging daily table tennis activity, optimized for
**fastest entry / least typing** (tap chips / steppers / dropdowns in the GUI).

### Decisions
- Match notation: `D:` = Doubles (default = Singles); W/L = Win/Loss; numbers in parentheses = set
  score; multiple comma-separated groups = multiple matches → **each pair is one match**.
- Storage: **SQLite** + Excel/CSV export button.
- Run: **local web**, single command `start.bat` → clears cache + opens a new tab in the running Chrome.
- Stack: **FastAPI (Python) + React (Vite + TypeScript)**.
- UI labels: **English** (Train with Coach, Practice Match, Overall...).
- Machine: Win11, i9, 32GB RAM, RTX 5060Ti 16GB.

## Data analysis from the Excel file
Each week is one block: columns = 7 days (Mon→Sun), rows = categories. Row types (as built):
1. **Duration** (Train with Coach, Backhand with Partner, Serve) — e.g. "1 hour", "45 mins".
2. **Checklist** (Physical Training) — tick exercises; cell turns yellow at ≥70% ticked.
3. **Match** (Practice Match, Official Match) — `W(3-0,3-1)`, `D: L(2-3)`, event name ("BBTV Open"),
   or "Travel".
4. **Rating** (Overall) — auto-generated colored cell: green / yellow / red (not manual).

→ Each individual match is one record; the display string `W(3-2,3-1)` is generated by grouping by
(discipline, result). W/L is derived from my_sets vs opp_sets.

## Multi-tab architecture (extensible)
Feature-based modularity on both frontend & backend → adding a tab = add one folder + register one line.

- **Frontend tab registry:** each tab is a module under `src/tabs/<tab>/`; `src/tabs/registry.ts`
  declares `{id,label,icon,component,enabled}`; `AppShell` builds the tab bar + router. Unbuilt tabs
  → `enabled:false` / ComingSoon.
- **Backend feature modules:** each tab has `app/features/<feature>/` (router/models/schemas/service);
  `app/features/registry.py` collects routers; `main.py` includes them all. Tab 1 = feature `tracker`.
- Shared: `src/shared/` (FE), `app/core/` (BE).

## Data model (SQLite)
Tables are **namespaced per feature** (prefix `tracker_*`) in the shared SQLite DB so future tabs
(tactics, supplementary drills, etc.) add their own `<feature>_*` tables without name collisions.
Tab 1 only needs the rows below; later tabs extend the schema, not rewrite it.

- `tracker_category`(id,key,label,type[duration|checklist|match|rating],color_group[green|yellow|none],sort_order)
- `tracker_activity`(id,date,category_id,duration_minutes,note)
- `tracker_match`(id,date,category_id,discipline[singles|doubles],best_of[3|5|7],my_sets,opp_sets,event_id,is_nonplaying,nonplaying_label,note,order_index)
- `tracker_event`(id,name) — autocomplete
- `tracker_physical_check`(id,date,item_key) — one ticked exercise (Physical Training checklist)

(`day_rating` was dropped — Overall is computed, not stored.)

## UI Tab 1 — fast entry, minimal typing
- Weekly grid (WeekGrid) like Excel. One shared **PeriodControl** (Day / Week /
  Month / Year / Custom + ◀ Today ▶) drives both the grid and the Analysis panel.
  Future days are not editable; the app opens on the latest week with data.
- **Duration cell → chips:** 15m·30m·45m·1h·1h30·2h·Custom (one tap).
- **Physical Training cell → checklist:** tick exercises (Wall Sit, Sit-ups,
  Plank, Squats, Obliques, Stretching); cell fills yellow at ≥70% ticked.
- **Match cell → form (dropdown-driven, no typing):**
  1. Discipline toggle: **Singles / Doubles**.
  2. Format selector: **BO3 / BO5 / BO7** (default **BO5**).
  3. **Score picker**: valid final scores as tap-buttons (wins green, losses red).
  4. "+ Add match"; event autocomplete; quick "Travel"/"Rest".
  - The Excel-style string (`D: W(3-1,3-2)`) is display/export only — never typed.
- **Overall cell → auto-generated** green/yellow/red (read-only, not buttons).
- **Analysis panel** (inline, below the grid): summary cards + comparison chart
  (Columns / Line) + training-time-by-category bars; uses the shared timeline.
- Speedups ("Copy yesterday", "Repeat last week", "Quick add Today") — deferred.

## API (`/api/tracker/...`)
- `GET /categories` · `GET /last-date` · `GET /weeks?start=`
- upsert `/activities`, CRUD `/matches`, `PUT /physical-checks` + `GET /physical-items`
- `GET /events?q=` · `GET /stats?from=&to=` · `GET /breakdown?from=&to=&unit=`
- `GET /export?from=&to=&format=`

## Run
`start.bat`: install deps (first run) → fresh frontend build (clears cache) → run uvicorn (port 8000)
→ open a new Chrome tab. Static is served with no-cache headers.

## Verification
Open localhost:8000 → Excel-like grid; enter duration / single & multi-match / doubles / Travel /
physical checklist; Overall colors itself; reload keeps data; timeline navigation moves grid +
Analysis together; export .xlsx matches.

## Implementation adjustments
